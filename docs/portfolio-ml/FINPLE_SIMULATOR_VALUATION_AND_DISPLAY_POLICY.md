# FINPLE 공개 시뮬레이터 평가·표시 정책

## 평가 기준

- 공개 시뮬레이터는 목표비중 기반 포트폴리오 분석 도구다.
- 현재가와 수량은 공개 계산의 필수값이 아니며, 외부 현재가 API를 공개 시뮬레이터에서 호출하지 않는다.
- 자산 평가금액은 `시작 평가금액 × 목표비중 ÷ 100`으로 계산한다.
- 기존 저장자료의 `quantity`와 `price`는 호환을 위해 보존하지만 migration 이후 runtime 계산에는 사용하지 않는다.
- quantity/price-only legacy 저장자료는 load 단계에서만 `quantity × price` 비율로 목표비중을 생성한다. 기준을 만들 수 없으면 계산을 보류한다.
- 이 정책은 AI 트레이딩의 개인계좌 KIS 조회·주문 경로와 분리되며, canonical CSV 갱신으로 변경되지 않는다.

## 표시 기준

- 읽기 전용 지표의 확인된 숫자 0은 `-`로 표시한다.
- 사용자가 편집하는 목표비중 input의 0은 `0.00`으로 유지한다.
- provider error는 `확인 필요`로 표시하고, missing 상태는 기존 안내 문구를 유지한다.
- 일반 배당과 비일반 현금분배의 필드와 의미는 구분한다.
- Step 1, Step 2, Step 3, 텍스트 리포트와 인쇄/PDF는 같은 읽기 전용 metric resolver를 사용한다.
